# Flip the Tables — Open Development

Flip the Tables is a free Christian Bible-reading app in development.

This repository is the public development workspace. Only reviewed, legally redistributable source code, artwork, and Scripture content should be included here.

The original private repository, Android permanent signing credentials, publisher correspondence, owner files, and release signing process remain private.

**Status:** Public-source migration and testing in progress. This repository does not currently provide a permanently signed, upgrade-safe Android release.
